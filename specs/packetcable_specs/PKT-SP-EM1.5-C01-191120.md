# PKT-SP-EM1.5-C01-191120 - Event Messages Specification

## Document Information
- **Title**: Event Messages
- **Document Control Number**: PKT-SP-EM1.5-C01-191120
- **Status**: Closed
- **Date**: November 20, 2019
- **Publisher**: Cable Television Laboratories, Inc. (CableLabs)

## Purpose
This specification describes the Event Messages used for billing and usage collection within the PacketCable architecture. Event Messages capture network usage information that, when correlated by the Record Keeping Server (RKS), provides complete Call Detail Records (CDRs).

## Scope
- Event Message architecture definition
- Services requiring Event Messages
- Event Message format and coding
- Transport protocols (RADIUS mandatory, FTP optional)
- Support for billing, fraud detection, and network usage monitoring

### Event Message Attributes (Section 10)
- **EM_Header**: Common header with BCID, timestamps, element info
- **Billing Correlation ID (BCID)**: Unique identifier for correlating events
- **Call_Termination_Cause**: Reason for call termination
- **Trunk Group ID**: PSTN trunk identification
- **QoS Descriptor**: Quality of Service parameters
- **Electronic Surveillance Indication**: PCES support attributes

## Key Concepts

### Billing Correlation ID (BCID)
A unique identifier generated by the CMS that links all Event Messages belonging to a single call or service instance. Contains:
- Element ID
- Time Zone
- Event Counter
- Event Timestamp

### TLV Format
Transport-independent Type-Length-Value encoding for Event Message attributes.
